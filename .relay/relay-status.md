- **`card-detail-multi-surface-view.md`** — DESIGNED. Build first (after prereq `engine-ops-still-append-to-card-body`).   - New module: new `card_artifacts_index` RPC method. Major rewrite of `src/ui/views/card_detail.ts`.

- **`card-detail-op-controls-and-button-states.md`** — DESIGNED. Build second (parallel-track with above). Replaces monolithic `Work this card` with per-op sidebar buttons (Analyze · Plan · Review · Implement · Verify · Resolve · Work all). Implements 4-state button machine (Idle / Running / Halted-by-chat ["Continue this card"] / Halted-by-assist). Per-op column-eligibility matrix. New RPCs `op_invoke` and `card_resume`. Card-detail-scoped keyboard shortcuts via existing global dispatcher.
  - New modules: `op_invoke` RPC, `card_resume` RPC, `Conductor.resumeCard()`, `cardKeyHandler` hook in `src/ui/lib/keys.ts`.

- **`chat-driven-description-authoring.md`** — DESIGNED. Build third (after #1 and #2). The largest feature by lines-of-code and the highest-risk by API surface. Extends `ModelAdapter` with optional `invokeWithTools` (Claude adapter implements; others fall back to single-shot). New `src/engine/ops/chat_agent.ts` with 4-tool surface (grep / read / glob / propose-description-edit). New RPCs `chat_apply_edit` and `chat_proposed_edit_get`. Diff-preview UI in chat with Apply/Reject buttons.
  - New modules: adapter `invokeWithTools` extension, `src/engine/ops/chat_agent.ts`, `chat_apply_edit` + `chat_proposed_edit_get` RPCs.
  - V1 scope: investigation capped at 1 round of tool calls before reply.

- **`column-transition-op-triggering.md`** — DESIGNED. Build fourth (after #2). When a card moves columns (drag-drop, keyboard, or chat-triggered), invoke the corresponding op per autonomy policy. New shared `src/ui/lib/column_ops.ts` with the COLUMN_OPS_MAP. Extends `board_dnd` and `board_keys` drop/move handlers. Maps each forward column-edge to its op (analyze+plan / review / implement / verify / notebook / resolve).
  - New module: `src/ui/lib/column_ops.ts`. No server-side changes.

- **`brain-halt-on-user-chat.md`** — DESIGNED. Build fifth (after #2 and #3). User chat on a card the conductor is currently running halts the brain at the next safe op-boundary (after `op_complete`, before next `op_start`). New halt reason `'user-chat'` on the existing `conductor-halt` event. `RuntimeStore.userTouched` set + `Conductor.resumeCard()` + `resumeQueue` drain in `pickEligibleCard`. In full autonomous mode with no user chat, no halt fires.
  - Modifies: `src/daemon/runtime.ts` (userTouched set), `src/engine/ops/chat.ts` (markUserTouched call), `src/conductor/loop.ts` (resumeCard + halt check + resumeQueue).

- **`card-detail-run-history-surface.md`** — DESIGNED. Build sixth (polish; after #1). Per-op `⋯` history toggle expands a list of all past runs for that op on this card, each clickable to view its artifact. New RPC `card_runs_list` (globs `.conductor/runs/*-<cardId>/`). Section state machine extends with `viewing-history` state.
  - New module: `card_runs_list` RPC. Possible extension to `src/agent/runlog.ts` prune logic for artifact dirs.
