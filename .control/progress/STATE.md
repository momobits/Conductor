## Recent decisions (last 3 ADRs)
- No formal ADRs filed during phases 13-16. Notable invariants captured durably in implementation docs (and re-asserted in journal entry below):
  - **H3-not-H2 invariant for in-section preambles** (phase 13). When a SYSTEM_PROMPT instructs the model to emit a structured sub-section inside what `appendSection` wraps under an H2 heading, the model's sub-section MUST use H3. `extractSection`'s regex `/\n##\s+/` matches H2 only. Verified for `plan.ts` preamble; transferable to any future "structured-preamble-in-section" pattern.
  - **EventBus subscriber-lifecycle invariant: writer.close() MUST run BEFORE bus.close()** (phase 14). Encoded structurally in `daemon/index.ts:shutdown` via `try { await brainLog.close(); } finally { bus.close(); }`. ADR-worthy when n ≥ 3 persistent subscribers (currently n=1 with brain log).
  - **`keepDays=0 → cutoff=Infinity` semantic** (phase 14). `pruneRuns` and `pruneBrainLog` both treat keepDays=0 as "time-window disabled, defer to keepLastN." Future writer-with-prune work should match. Adversarial review caught a `-Infinity` draft.
  - **Close-drain invariant for serialized Promise chains** (phase 14). `closed` flag belongs in `onEvent` (upstream of scheduling), NOT in `appendLine` (downstream of scheduling). Source carries a NOTE comment; Test #4 in `brain_log.test.ts` guards it.
  - **WAD acknowledgement-only closures are valid Phase shapes** (phase 16). A P3 observation flagged for awareness with the issue itself recommending "no fix" closes via short-lifecycle: Analysis (validation + WAD rationale) + compact impl doc + archive with WAD banner. No plan/review/verify code-side work required.
- A formal ADR is **warranted** if a third op adopts the "settle resolved context first" pattern (Phase 12.1 head-of-userPrompt + Phase 13.1 model-output preamble are at n=2).
